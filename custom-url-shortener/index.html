Choose an alias that tells people what to expect

An alias replaces the random code at the end of a short URL. For example, https://pyc0.onrender.com/summer-sale is an illustrative format, not a live campaign link. A readable code can be easier to type from a poster or remember after a presentation.

How to create a custom short URL

  1. Open the shortening form and paste the full destination URL.
  2. Enter a name in Custom alias. Use 5–30 letters, numbers, underscores or hyphens.
  3. Select Shorten URL. If that alias is already assigned to a different destination, choose another name.
  4. Open the returned URL to check the destination before sharing it.

A custom alias is different from a custom domain

All links currently use pyc0.onrender.com. Choosing an alias does not let you replace that domain with your own brand. An alias also does not let you edit an existing link's destination through the public tool.

What happens if the name is taken?

An existing alias cannot be reassigned to another destination. Try a meaningful variation such as the event year or a shorter campaign title. Avoid names that suggest you represent another company.

Should I use a random code or an alias?

A random code is compact and convenient for messages where people tap the link. An alias is useful where someone may need to read or type it. Neither format makes a private destination public or hides sensitive data.

Can I measure clicks on an alias?

Yes. Paste the returned Pycoder URL into the Link Tracker. For comparing channels, use distinct aliases and destination URLs tagged with the UTM Builder. Without an alias, the service may reuse an existing link for the same destination.
