Use a short link and QR code together

Short URLs and QR codes solve different parts of the same sharing problem. A short link is convenient when someone can tap or copy a URL. A QR code is useful when the destination is being shown on another screen or printed on something physical.

With Pycoder, you can shorten the destination first and then create a QR code for that compact link. You can also generate a QR code directly from a normal web URL when shortening is unnecessary.

  • Social profiles and messaging apps.
  • Flyers, posters and event handouts.
  • Menus, brochures and product cards.
  • Presentations and classroom materials.
  • Campaign links that already contain UTM parameters.

Why shorten before making a QR code?

A QR code can contain a long URL directly, so shortening is not mandatory. Using a short redirect can still make management easier because the human-readable link is compact and the same Pycoder code can be checked with the URL Expander and Link Tracker.

If you are preparing a campaign, create the full tagged destination with the UTM Builder, shorten that final URL, and then generate the QR code. The person scanning the code reaches the same campaign destination through the short redirect.

Download and test before publishing

The Pycoder QR tool returns a PNG image that you can download or use in another document. Before printing a large batch of material, test the QR code on more than one phone and confirm that the destination is correct.

For public materials, keep enough white space around the code and avoid making it so small that phone cameras struggle to read it. If the underlying destination is especially important, test the short link itself as well as the QR image.
