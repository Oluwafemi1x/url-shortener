UTM parameters explained

A practical guide to building cleaner campaign tracking links without mixing up source, medium and campaign names.

URL ShortenerQR GeneratorUTM BuilderLink Tracker

UTM parameters are query parameters added to a destination URL so analytics tools can identify where campaign traffic came from. They do not change the page itself; they add tracking labels to the URL.

utm_source

The source identifies the specific platform, publisher or origin of the traffic. Common values include facebook, linkedin, newsletter or the name of a partner.

utm_medium

The medium describes the channel type. Examples include social, email, cpc or referral. Keep your naming consistent so reports do not split the same channel across several spellings.

utm_campaign

The campaign name groups visits that belong to the same promotion, launch or initiative. A value such as september_launch can be reused across several sources and mediums.

utm_term and utm_content

Term is commonly used for keyword or targeting information. Content can distinguish different creative variations, buttons or placements inside the same campaign.

Build first, shorten second

UTM parameters can make a URL very long. Build the full campaign URL first, verify the parameters, then shorten the finished URL. The Pycoder UTM Builder can perform both steps in one page.

Use a naming convention

Choose lowercase names, avoid unnecessary spaces and agree on consistent values before a campaign begins. Consistency matters more than clever naming because analytics tools generally treat different values as different campaign dimensions.

Example campaign

If you are promoting a product launch from an email newsletter, you might use utm_source=newsletter, utm_medium=email and utm_campaign=product_launch. If the same campaign is also posted on LinkedIn, keep the campaign name the same and change the source and medium so reporting can separate the channels while still grouping them under one initiative.
